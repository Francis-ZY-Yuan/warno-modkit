WARNO build 210942 broke the 201602 toolkit in two places on the core side, both found by running it. `setup extract`
stopped on a map pack the install no longer has (`_4x2_Isura.dat`; the map ships `_4x2_Isura_Definition` with
`NDF/Maps/_4x2_Isura/*.txn`). `ndfrules extract` found no "must be defined" helper: the game's code is a new compiler
build, and the reader now tells a message helper by its shape, a small function that never returns, instead of a
size alone.

What changed for the stock corpus. The archive chain was rebased to four revisions. The game's own NDF moved from
`Glad.dat` (`.ndfbin`) to `Transactions.dat` (`.txn`, compiled NDF like `.ndfbin`): 147 of Glad's 178 files under
the same names, the rest renamed (`GFX/Constantes` is now `Scenario/GFX/Constantes`). The game's Glad file-list
class is gone, so Glad's copy is no longer stock. Scenario and map `_Definition` packs also ship `.txn` files.
ModManager's Gameplay tag now lists `.txn` files, with `GFX/CriticalEffects` in and `GFX/UnitConstantes` out.

What changed in the load-time rules: 3,663 rules on 1,415 classes, against 3,870 on 1,565 for 201602. All 663 stock
files of 210942 (1.56 million objects) pass. Every removed row is explained by the exe: 271 went with 172 classes
the game dropped (153 of them Python-binding classes; also `TScenarioLoadInfo`, `TMapLoadInfo` and
`TGDDescriptorLaunchEffetStandard`, replaced by `TScenarioDefinition`, `TMapDefinition` and
`TGDDescriptorLaunchEffetMap`). 61 more are gone or reworded on classes that remain, whose validation no longer names
the property. Among them, `TGDDescriptorChangeStress` no longer tests `DamageType`, only `Group`, and LOD selectors
renamed `CameraMoverManager` to `Camera`. 56 rows are on 22 new classes and 61 are new checks. Most of the new checks
come from new features, such as weapons without `Ammunition`. For the 6 new `TCameraMoverTranslateIfMouseInBorder`
conditions and 4 other new messages, a check the 201602 reader missed cannot be ruled out, since the 201602 exe is
gone.
