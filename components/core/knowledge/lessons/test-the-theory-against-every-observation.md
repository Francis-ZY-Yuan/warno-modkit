title: Before handing over a fix from analysis, test it against every observation, the build that worked included
trials: [2026-11-02-kreide-op-relaunch-loop]
---
Two launches were lost to fixes that rested on an untested inference and on a mapping read from list order rather
than from the code's own labels. The observation that pointed at the real cause had been explained away. Also check
every input the code reads, not only the one you changed.
