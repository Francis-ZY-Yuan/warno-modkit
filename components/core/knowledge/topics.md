# Topics

The topics this component's mechanisms are filed under (see [README.md](README.md)). Each mechanism names one to
three of them in its `topics` field.

## files-and-formats: Files and formats
The game's archives and file formats (edat, compiled NDF, dictionaries and tokens), and how the toolkit reads and writes them.

## loading-and-crashes: Loading and crashes
What the game checks when a mod loads, how a load or a launch fails, and how to read a crash.

## mod-packaging: Mod packaging
How a mod folder is laid out, activated, kept apart from other mods, and shared.

## game-updates: Game updates
What changed between game builds, and the facts most likely to change with the next update.
