# Requests and notices

warno-modkit is for single-player scenario mods only. This page says where to raise things.

- **Bugs and ideas.** Open an issue. Requests for multiplayer advantages, for changes to the game's executable, or for
  ways around the game's limits are out of scope and will be closed.
- **Corrections.** If the README misses or misdescribes another project, open an issue naming it.
- **Rights holders.** To have something in this repository changed or removed, open an issue naming the files, or use
  GitHub's [DMCA process](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy).
